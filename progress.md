# Прогресс: тестовое задание «Фронтенд-разработчик React» (GREEN-API)

## Задача
Веб-интерфейс для отправки и получения **текстовых** сообщений через [GREEN-API](https://green-api.com/).
Вариант мессенджера: **Telegram** (разрешено заданием вместо MAX).
Визуальный прототип — веб-версия мессенджера (минималистичный чат).

### Ожидаемый сценарий
1. Пользователь вводит `idInstance` и `apiTokenInstance`.
2. Вводит номер телефона получателя → создаётся новый чат.
3. Пишет текст → отправка через `sendMessage`.
4. Получатель отвечает в Telegram → ответ появляется в чате (`receiveNotification` + `deleteNotification`).

## Технические заметки по API (Telegram-инстанс)
- Базовый URL: `{apiUrl}/waInstance{idInstance}/{method}/{apiTokenInstance}`
  - `apiUrl` у каждого инстанса свой (видно в личном кабинете, напр. `https://4100.api.green-api.com`); дефолт — `https://api.green-api.com`. В форме входа — поле `apiUrl` с подставленным значением по умолчанию.
- **Отправка:** `POST sendMessage` body `{ chatId, message }` → `{ idMessage }`. Лимит текста 4096 символов.
- **chatId в Telegram:** по номеру телефона `79876543210@c.us`, либо числовой ID `10000000`.
- **Получение:** `GET receiveNotification?receiveTimeout=5..60` → `{ receiptId, body }` или `null`; затем обязательно `DELETE deleteNotification/{receiptId}`.
  - Нужно, чтобы у инстанса был **пустой webhookUrl** и включены входящие уведомления.
- **Подвох:** чат создаём по телефону (`7999...@c.us`), а входящее сообщение приходит с `senderData.chatId = "10000000"` (Telegram ID) и `senderData.senderPhoneNumber`. Сопоставлять входящие с чатом нужно по `chatId` **или** по `senderPhoneNumber`.
- Типы уведомлений, которые обрабатываем: `incomingMessageReceived` (+ `outgoingMessageReceived` / `outgoingAPIMessageReceived` — сообщения, отправленные с телефона/API), только `textMessage` / `extendedTextMessage`. Остальные — просто удаляем из очереди.
